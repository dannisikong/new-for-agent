# 创建舞会智能体

**一句话总述：**把前面做好的四件工具（宾客检索、网络搜索、天气、HF 统计）整合成一个完整智能体 Alfred——三框架任选（CodeAgent / AgentWorkflow / LangGraph），实测四种舞会场景，Alfred 正式上线服务。

## 一、组装思路：复用而非重写

不重复实现已有工具，直接从之前保存的模块导入：

- `tools.py`：网络搜索、天气、HF 统计工具
- `retriever.py`：宾客数据集加载与检索工具

## 二、三框架组装 Alfred

### smolagents（CodeAgent）

```python
import random
from smolagents import CodeAgent, InferenceClientModel

from tools import DuckDuckGoSearchTool, WeatherInfoTool, HubStatsTool
from retriever import load_guest_dataset

model = InferenceClientModel()
search_tool = DuckDuckGoSearchTool()
weather_info_tool = WeatherInfoTool()
hub_stats_tool = HubStatsTool()
guest_info_tool = load_guest_dataset()

alfred = CodeAgent(
    tools=[guest_info_tool, weather_info_tool, hub_stats_tool, search_tool], 
    model=model,
    add_base_tools=True,   # 添加额外基础工具
    planning_interval=3    # 每 3 步做一次规划
)

```

**两个增强参数：**

- **add_base_tools=True：**自动附加基础工具集
- **planning_interval=3：**每执行 3 步就让智能体停下来做一次整体规划，提升长任务质量

### LlamaIndex（AgentWorkflow）

```python
from llama_index.core.agent.workflow import AgentWorkflow
from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI

from tools import search_tool, weather_info_tool, hub_stats_tool
from retriever import guest_info_tool

llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")
alfred = AgentWorkflow.from_tools_or_functions(
    [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool],
    llm=llm,
)

```

### LangGraph（图结构）

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage
from langgraph.prebuilt import ToolNode, tools_condition
from langgraph.graph import START, StateGraph
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

from tools import DuckDuckGoSearchRun, weather_info_tool, hub_stats_tool
from retriever import guest_info_tool

search_tool = DuckDuckGoSearchRun()
llm = HuggingFaceEndpoint(repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
                          huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN)
chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {"messages": [chat_with_tools.invoke(state["messages"])]}

builder = StateGraph(AgentState)
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))
builder.add_edge(START, "assistant")
builder.add_conditional_edges("assistant", tools_condition)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

```

**回顾：**这就是第 16 章学的 ReAct 循环图——assistant 决定调工具还是直接回答。

## 三、端到端实测（4 个场景）

### 示例1：查宾客信息

```python
response = alfred.run("Tell me about 'Lady Ada Lovelace'")

```

**Alfred 的回答：**Lady Ada Lovelace 是杰出的数学家和朋友，以数学与计算的开创性工作著称，被誉为第一位计算机程序员（查尔斯·巴贝奇分析机的贡献）。邮箱：ada.lovelace@example.com。

**所用工具：**guest_info_tool（宾客检索）

### 示例2：查天气判断烟花

```python
response = alfred.run("What's the weather like in Paris tonight? Will it be suitable for our fireworks display?")

```

**Alfred 的回答（随机，两种可能）：**

- 巴黎晴朗 25°C —— 完美适合烟花，能见度极佳
- 巴黎下雨 15°C —— 可能不适合烟花表演

**所用工具：**weather_info_tool（天气）

### 示例3：惊艳 AI 研究者

```python
response = alfred.run("One of our guests is from Qwen. What can you tell me about their most popular model?")

```

**Alfred 的回答：**Qwen 最流行的模型是 Qwen/Qwen2.5-VL-7B-Instruct，下载量 3,313,345 次。（Google 的则是 google/electra-base-discriminator，28,546,752 次下载）

**所用工具：**hub_stats_tool（HF 统计）

### 示例4：多工具组合（重头戏）

```python
response = alfred.run("I need to speak with Dr. Nikola Tesla about recent advancements in wireless energy. Can you help me prepare for this conversation?")

```

**Alfred 的回答（组合检索+搜索）：**

- **宾客信息：**Dr. Nikola Tesla 是你的大学老友，最近为新的无线能量传输系统申请了专利，很想和你讨论；他对鸽子很着迷，可以当闲聊话题。邮箱：nikola.tesla@gmail.com
- **无线能量最新进展：**基于网络搜索的结果……

**所用工具：**guest_info_tool + search_tool（多工具协作）

**这正是 Agentic RAG 的价值：**一个智能体自主决定"先查宾客资料、再搜最新进展"，组合多个工具给出完整答案。

## 四、关键收获

- **模块化复用：**工具封装在 tools.py / retriever.py，组装时导入即可
- **增强配置：**add_base_tools、planning_interval 让智能体更稳
- **三框架等价：**同样的工具集，CodeAgent / AgentWorkflow / LangGraph 都能组装
- **多工具协同：**复杂问题由智能体自主编排多个工具解决

## 五、新手常见误区

- **误区1：每次从零实现工具。**应封装成模块，组装时导入复用。
- **误区2：以为 tools 列表越少越好。**四个工具各司其职，组合才能应对复杂问题。
- **误区3：忽略 planning_interval。**长任务不做规划，容易跑偏。
- **误区4：LangGraph 忘连 tools→assistant。**没有回边就没有多轮工具调用。

## 六、本节小结

宾客检索 + 搜索 + 天气 + HF 统计四件工具整合完毕，Alfred 舞会管家正式上线：能查宾客、排烟花、聊模型、备谈资。第三单元的 Agentic RAG 用例完整落地。
