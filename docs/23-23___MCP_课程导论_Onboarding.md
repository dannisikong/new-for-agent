# 23 · MCP 课程导论（Onboarding）

## 一、这门课是什么

Hugging Face 与 Anthropic 合作推出的**免费 Model Context Protocol（MCP）课程**，目标是让学习者从入门到能基于 MCP 构建自己的 AI 应用。MCP 是当前 Agent 生态最核心的协议标准，OpenAI、Anthropic、Google、MongoDB 等主流厂商均已支持。

## 二、课程目标

- 从理论、设计、实践三个层面理解 MCP
- 学会使用成熟的 MCP SDK 和框架构建应用
- 完成真实用例作业，并获得证书
- 理解 MCP 如何让 AI 应用安全地接入外部数据与工具

## 三、课程结构

| 章节 | 主题 | 内容 |
|-|-|-|
| 0 | Onboarding | 账号注册、工具准备、社群加入 |
| 1 | MCP 基础、架构与核心概念 | MCP 的核心概念、架构、组件，跑通一个简单用例 |
| 2 | 端到端用例：MCP in Action | 构建一个可分享的完整 MCP 应用 |
| 3 | 部署用例：MCP in Action | 基于 Hugging Face 生态和合作方服务，部署一个真实运行的 MCP 应用 |
| 4 | 加分单元 | 合作方库与工具的进阶用法 |

## 四、证书与节奏

- **基础证书**：完成 Unit 1 即可，适合想快速了解 MCP 趋势的人
- **完成证书**：完成 Unit 2 + 3（两个用例），适合想真正动手做应用的人
- 节奏：每周约 3-4 小时，共 5 周左右

## 五、前置要求

- 理解 AI 与 LLM 基本概念
- 熟悉软件开发与 API 概念
- 会至少一门语言（课程示例用 Python / TypeScript）

## 六、合作方

Anthropic（课程共建）、Gradio、Continue、llama.cpp。课程为开源项目，欢迎 GitHub 提 issue / PR。

## 七、对本项目的意义

本项目（new-for-agent）下一步待办之一就是"实现自己的 MCP server"。这门课的 Unit 1 + Unit 2 可以直接作为学习路径，把知识检索 + web 搜索包装成 MCP server，接入 Claude Code / Cursor。
