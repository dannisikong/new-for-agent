# 宾客RAG检索工具

**一句话总述：**为 Alfred 创建一个自定义 RAG 工具：把宾客数据集（姓名/关系/简介/邮箱）加载成文档，用 **BM25Retriever** 实现关键词检索，让 Alfred 在舞会上能随时按需查到宾客的准确信息。

## 一、为什么舞会需要 RAG？

想象 Alfred 在宾客间寒暄，需要随时回忆每个人的具体细节。传统 LLM 难以胜任，因为：

1. **宾客名单是特定事件数据**——不在模型的训练数据里
2. **宾客信息可能频繁变化更新**
3. **Alfred 需要检索精确细节**，比如邮箱地址

**RAG 的优势：**把"检索系统 + LLM"结合，Alfred 可以按需访问准确、最新的宾客信息。

## 二、项目结构（HF Space 结构化项目）

本单元在 HF Space 中以结构化 Python 项目开发智能体，把不同功能组织到独立文件：

| 文件 | 作用 |
|-|-|
| **tools.py** | 提供智能体的辅助工具 |
| **retriever.py** | 实现检索函数，支持知识访问 |
| **app.py** | 整合所有组件为完整智能体（本单元最后完成） |

参考线上示例：agents-course/Unit_3_Agentic_RAG（HF Space，可直接克隆实验）。

## 三、数据集概览

数据集 `agents-course/unit3-invitees` 包含每位宾客的字段：

| 字段 | 说明 |
|-|-|
| **Name** | 宾客全名 |
| **Relation** | 宾客与主人的关系 |
| **Description** | 简介或有趣事实 |
| **Email Address** | 联系信息（发邀请或跟进） |

> 实际场景可扩展：饮食偏好、礼物兴趣、要避免的对话话题等。

## 四、三步构建流程

### Step 1：加载并准备数据集

用 Hugging Face `datasets` 库加载数据，转换为 `Document` 对象列表：

```python
import datasets
from langchain_core.documents import Document

# 加载数据集
guest_dataset = datasets.load_dataset("agents-course/unit3-invitees", split="train")

# 转换为 Document 对象
docs = [
    Document(
        page_content="\n".join([
            f"Name: {guest['name']}",
            f"Relation: {guest['relation']}",
            f"Description: {guest['description']}",
            f"Email: {guest['email']}"
        ]),
        metadata={"name": guest["name"]}
    )
    for guest in guest_dataset
]

```

**做了什么：**加载数据集 → 每条宾客记录格式化为 Document（内容+元数据）→ 存入列表，准备好供检索使用。

### Step 2：创建 Retriever 工具（BM25）

用 **BM25Retriever** 创建检索工具（无需嵌入的强大文本检索算法；更高级语义检索可考虑 embedding 检索器，如 sentence-transformers）。

smolagents 版（Tool 类）：

```python
from smolagents import Tool
from langchain_community.retrievers import BM25Retriever

class GuestInfoRetrieverTool(Tool):
    name = "guest_info_retriever"
    description = "Retrieves detailed information about gala guests based on their name or relation."
    inputs = {
        "query": {
            "type": "string",
            "description": "The name or relation of the guest you want information about."
        }
    }
    output_type = "string"

    def __init__(self, docs):
        self.retriever = BM25Retriever.from_documents(docs)

    def forward(self, query: str):
        results = self.retriever.invoke(query)
        if results:
            return "\n\n".join([doc.page_content for doc in results[:3]])
        else:
            return "No matching guest information found."

guest_info_tool = GuestInfoRetrieverTool(docs)

```

LlamaIndex 版（FunctionTool）：

```python
from llama_index.core.tools import FunctionTool
from llama_index.retrievers.bm25 import BM25Retriever

bm25_retriever = BM25Retriever.from_defaults(nodes=docs)

def get_guest_info_retriever(query: str) -> str:
    """Retrieves detailed information about gala guests based on their name or relation."""
    results = bm25_retriever.retrieve(query)
    if results:
        return "\n\n".join([doc.text for doc in results[:3]])
    else:
        return "No matching guest information found."

guest_info_tool = FunctionTool.from_defaults(get_guest_info_retriever)

```

LangChain 版（Tool）：

```python
from langchain_community.retrievers import BM25Retriever
from langchain_core.tools import Tool

bm25_retriever = BM25Retriever.from_documents(docs)

def extract_text(query: str) -> str:
    """Retrieves detailed information about gala guests based on their name or relation."""
    results = bm25_retriever.invoke(query)
    if results:
        return "\n\n".join([doc.page_content for doc in results[:3]])
    else:
        return "No matching guest information found."

guest_info_tool = Tool(
    name="guest_info_retriever",
    func=extract_text,
    description="Retrieves detailed information about gala guests based on their name or relation."
)

```

**工具设计要点（理解 step-by-step）：**

- **name / description / docstring：**帮助智能体理解何时、如何用这个工具
- **inputs / 类型注解：**定义工具期望的参数（这里是搜索查询）
- **BM25Retriever：**无需嵌入的检索算法
- **forward / 处理方法：**处理查询并返回最相关的宾客信息（前 3 条）
- **无结果兜底：**返回 "No matching guest information found."

### Step 3：整合工具与 Alfred（下一部分）

把检索工具和其他工具（网络搜索、天气、HF 统计）整合进完整智能体。

## 五、新手常见误区

- **误区1：以为 BM25 是唯一选择。**BM25 是好起点，但语义理解需求高时改用 embedding 检索器。
- **误区2：忘记给工具写清 description。**智能体靠描述决定何时用工具，描述不清会导致误用。
- **误区3：返回结果不设上限。**不加 [:3] 会一次返回太多文档，拖慢回答。
- **误区4：无结果时抛异常。**应优雅返回提示信息，而不是让流程崩溃。

## 六、本节小结

宾客 RAG 工具 = 数据集加载（Document 化）+ BM25 检索 + 工具封装（三框架任选）。Alfred 现在能按宾客姓名或关系快速查到准确信息了。
