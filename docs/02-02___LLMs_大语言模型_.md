# LLMs（大语言模型）

**一句话总述：**LLM是以Transformer解码器架构为主的AI模型，核心原理是根据上文token预测下一个token，作为Agent的推理大脑。

## 一、什么是大语言模型（LLM）

LLM（Large Language Model）是一类擅长**理解和生成人类语言**的 AI 模型：

- **训练方式：**在海量文本数据上训练，从中学习语言的模式、结构甚至细微语义
- **规模：**通常拥有数百万到数十亿参数
- **在 Agent 中的角色：**是 Agent 的"大脑"，负责理解指令、维护上下文、制定计划、决定调用哪些工具

**常见例子：**GPT-4（OpenAI）、Llama（Meta）、Gemini（Google）、Deepseek-R1（DeepSeek）等。

## 二、Transformer 的三大架构

绝大多数现代 LLM 都基于 Transformer 架构（2018 年 Google 发布 BERT 后兴起），它有三种类型：

| 类型 | 干什么的 | 代表模型 | 典型用途 | 规模 |
|-|-|-|-|-|
| **Encoder（编码器）** | 把输入文本转成稠密向量表示（embedding） | BERT（Google） | 文本分类、语义搜索、命名实体识别 | 百万级参数 |
| **Decoder（解码器）** | 逐个生成 token，续写序列 | Llama（Meta） | 文本生成、聊天机器人、代码生成 | 十亿级参数（10^9） |
| **Seq2Seq（编码器-解码器）** | 编码器处理输入，解码器生成输出 | T5、BART | 翻译、摘要、改写 | 百万级参数 |

**关键点：**我们常说的"大语言模型 LLM"，通常特指 **Decoder 解码器架构**、参数达数十亿的模型。因为要生成文本，解码器是最自然的选择。

## 三、Token：模型眼中的"单词"

LLM 不是按"单词"处理文本的，而是按 **token（词元）**：

- 一个 token 可以理解为"半个词"或"子词单元"
- 例如英文约 60 万个单词，而 Llama 2 的词表只有约 3.2 万个 token
- token 可以组合：interest + ing → interesting；interest + ed → interested

除了普通 token，每个模型还有自己的**特殊 token（special tokens）**，用于标记结构的开始与结束，比如：

| 模型 | 提供方 | EOS 结束标记 | 作用 |
|-|-|-|-|
| GPT-4 | OpenAI | <\|endoftext\|> | 文本结束 |
| Llama 3 | Meta | <\|eot_id\|> | 序列结束 |
| Deepseek-R1 | DeepSeek | <\|end_of_sentence\|> | 文本结束 |
| SmolLM2 | Hugging Face | <\|im_end\|> | 指令或消息结束 |
| Gemma | Google | <end_of_turn> | 对话轮次结束 |

这些特殊 token 不用死记，但要理解：**模型靠它们区分"哪句话是用户说的、哪句是助手说的、什么时候该停"**。

## 四、核心机制：预测下一个 token

LLM 的原理简单但强大：**给定前面一串 token，预测下一个最可能的 token**。

1. 输入文本先被切分成 token
2. 模型计算每个 token 的含义与位置信息，得到序列表示
3. 模型为词表中的每个 token 打分，排序出"下一个 token"的概率
4. 根据策略选一个 token，拼到序列后面，继续预测下一个

这种"上一轮输出作为下一轮输入"的循环就叫 **自回归（autoregressive）**。循环会一直进行，直到模型预测出 EOS 结束标记才停止。

## 五、解码策略：怎么选下一个 token

- **贪心解码（Greedy）：**每次直接选分数最高的 token。简单，但可能陷入局部最优。
- **束搜索（Beam Search）：**同时探索多条候选序列，最后选整体总分最高的那条——即使个别 token 分数低，也能得到全局更好的句子。

## 六、Attention：注意力机制

Transformer 架构的核心是 **注意力机制（Attention）**：预测下一个词时，句子里的每个词重要性不同。

**例子：**在 "The capital of France is ..." 这句话里，France 和 capital 携带的信息量最大，模型会把"注意力"重点放在它们身上。

由此引出 **上下文长度（context length）**：模型最多能处理的 token 数量，也就是它注意力的最大覆盖范围。上下文越长，模型"记住"的信息越多。

## 七、Prompt：输入决定了输出

既然 LLM 唯一的工作就是"看着所有输入 token 预测下一个"，那么**你输入什么（Prompt），直接决定输出质量**。

精心设计 Prompt，可以有效引导模型输出你想要的结果。这是 Agent 开发中非常重要的一项技能。

## 八、训练流程：预训练 + 微调

1. **预训练（Pre-training）：**在大规模文本上自监督学习"预测下一个词"，掌握语言结构和通用规律，获得泛化能力。
2. **微调（Fine-tuning）：**在预训练基础上，用有标注数据针对特定任务优化，例如对话、工具调用、分类、代码生成等。

## 九、怎么使用 LLM

- **本地运行：**需要足够的硬件（GPU/显存）。
- **云端 API：**通过推理服务调用，如 Hugging Face Serverless Inference API。课程后续主要用 API 方式。

## 十、LLM 在 Agent 中的作用

LLM 是 Agent 的**核心组件**，提供理解与生成语言的基础能力：解释用户指令、保持对话上下文、制定计划、决定调用哪个工具。**一句话：LLM 就是 Agent 的大脑。**
