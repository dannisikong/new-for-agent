# 24 · MCP Unit 1 导论：协议基础与核心概念

## 一、本单元学习目标

- 理解 MCP 是什么、为什么重要
- 掌握 MCP 的关键概念与术语
- 了解 MCP 解决的集成难题
- 理解 MCP 的收益与设计目标
- 跑通一个最简单的 MCP 集成示例

## 二、为什么需要 MCP

LLM 能力再强，也受限于训练数据，拿不到实时信息和外部工具。AI 要真正有用，必须能连接外部数据源、工具和环境。MCP（Model Context Protocol）就是为 AI 模型与外部世界之间提供**统一的信息与能力传输通道**，让这种互操作性成为可能。

## 三、本单元结构

1. **什么是 MCP**：定义及其在 AI 生态中的角色
2. **核心概念**：MCP 的基本术语与组件
3. **集成难题**：重点理解「M×N 集成问题」
4. **收益与目标**：标准化、AI 能力增强、互操作性
5. **简单示例**：跑通一个 MCP 集成 demo

## 四、关键预告：M×N 集成问题

这是理解 MCP 价值的核心：在 MCP 之前，每个 AI 应用（M 个）要接每个外部工具/数据源（N 个），需要写 M×N 套定制对接代码。MCP 通过一层标准协议，把 M×N 变成 M+N——所有 AI 端只认 MCP 协议，所有工具方也只实现一次 MCP server。这和当年 USB 统一各种外设接口是同一个思路。
