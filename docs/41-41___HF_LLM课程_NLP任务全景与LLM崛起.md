# 41 · HF LLM 课程 1.2：NLP 任务全景与大语言模型的崛起

> 来源：https://huggingface.co/learn/llm-course/chapter1/2

## 一句话总述

NLP 的目标不只是"认识每个词"，而是理解**词的上下文**；大语言模型用规模+上下文学习+涌现能力，把"一个任务造一个专用模型"的旧范式，换成"一个大模型 prompt/微调通吃"，但同时带来幻觉、偏见、上下文窗口等新局限。

---

## 一、NLP 到底做什么（五类任务）

| 类别 | 例子 |
|---|---|
| **整句分类** | 评论情感、邮件是否垃圾邮件、句子语法是否正确、两句话是否逻辑相关 |
| **句中逐词分类** | 词性标注（名/动/形）、命名实体识别（人/地点/组织） |
| **生成文本内容** | 续写 prompt、完形填空（masked word 补全） |
| **从文本抽答案** | 给定问题+上下文，从上下文里抽取答案 |
| **从输入生成新句** | 翻译、摘要 |

> NLP 不限于纯文字：还包括**语音识别**（音频转文字稿）和**计算机视觉**（给图像生成描述）。

---

## 二、LLM 的四个标志性特征

| 特征 | 含义 |
|---|---|
| **Scale 规模** | 参数从百万、十亿到千亿级 |
| **General capabilities 通用能力** | 不用为每个任务单独训练，就能做多种语言任务 |
| **In-context learning 上下文学习** | 直接从 prompt 里给的示例中学习，不改权重 |
| **Emergent abilities 涌现能力** | 模型规模变大后，会出现训练时没显式编程/预期的新能力 |

**范式转移**：过去 = 为每个 NLP 任务训练专用小模型；现在 = 一个大模型，用 prompt 或微调覆盖广泛任务。门槛降低，但效率、伦理、部署出现新挑战。

---

## 三、LLM 的五个重要局限（面试高频）

1. **幻觉 Hallucinations**：会一本正经地生成错误信息。
2. **缺乏真正理解**：纯靠统计模式运作，并不真正"懂"世界。
3. **偏见 Bias**：会复制训练数据/输入里的偏见。
4. **上下文窗口有限**：能看的文本长度有上限（在改进中）。
5. **算力资源需求大**：训练和推理都很贵。

---

## 四、为什么语言处理对机器很难

人读 "I am hungry" 立刻懂意思，也能轻易判断 "I am hungry" 和 "I am sad" 的相似度；机器却需要把文本表示成可学习的形式。即使有了 LLM，**歧义、文化语境、讽刺、幽默**仍是硬骨头——LLM 靠海量多样数据硬学，在很多复杂场景仍达不到人类水平。

---

## 五、面试可讲的一句话

> "NLP 的核心是理解上下文而不是孤立单词，五类任务覆盖分类/生成/抽取；LLM 靠规模、上下文学习和涌现能力实现'一模型多任务'，但幻觉、偏见和上下文窗口是它天生的局限，工程上必须靠 RAG、护栏和人在回路去补。"

---

## 六、新手误区

**误区1：LLM 等于 NLP 的全部**
**实际**：LLM 是 NLP 的子集/最新范式；词性标注、NER、情感分析等专用小模型仍大量在用。

**误区2：模型"懂"它说的话**
**实际**：它是统计模式，会自信输出错误（幻觉），所以生产环境要加校验与 RAG。

**误区3：in-context learning = 重新训练**
**实际**：上下文学习是从 prompt 示例里学，**不改权重**；要固化行为才需要微调。
