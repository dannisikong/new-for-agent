# 31 · 端到端 MCP 应用（Unit 2 开篇）

## 一句话总述

Unit 2 要从零做一个完整的 MCP 应用：用 Gradio 写一个情感分析 Server，部署到 Hugging Face Spaces，然后分别用 JS 和 Python 两种客户端连接它。

---

## 一、这个单元要做什么？

Unit 1 学了概念和 SDK，Unit 2 开始动手做一个完整项目。

**项目目标**：做一个"情感分析"的 MCP Server。

**三部分组成**：
1. **Server 端**：用 Gradio 建网页界面 + MCP 协议，暴露一个情感分析工具
2. **Client 端**：分别用两种方式连接同一个 Server（HuggingFace.js 客户端 + Python smolagents 客户端）
3. **部署**：把 Server 部署到 Hugging Face Spaces，让线上的 Client 也能连

**类比**：Unit 1 学了"USB 接口标准"，Unit 2 开始做一个 U 盘（Server），然后试两种电脑（Client）能不能插上去读数据。

---

## 二、为什么用 Gradio 做 Server？

Gradio 本来是做机器学习演示网页的，现在它内置了 MCP 支持。

好处：
- 一行 `gr.Interface` 同时生成网页界面 + MCP 协议接口
- 你不用自己写 HTTP 服务、不用处理 JSON-RPC
- 写个普通 Python 函数（比如情感分析），自动就变成 MCP Tool 了

**对比 FastMCP**：
- FastMCP：纯 MCP Server，只有接口没有界面
- Gradio MCP：既有网页界面可以手动测试，又有 MCP 接口给 AI 调用，一举两得

---

## 三、要用到的技术栈

| 部分 | 技术 | 说明 |
|---|---|---|
| Server | Gradio + TextBlob | 情感分析用 TextBlob 库，简单演示 |
| Client 1 | HuggingFace.js | JavaScript 客户端 |
| Client 2 | smolagents | Python 轻量 Agent 框架 |
| 部署 | Hugging Face Spaces | 免费托管 Server |

---

## 四、前置要求

- 完成 Unit 1 或了解 MCP 基本概念
- Python 3.10+、Node.js 18+
- 一个 Hugging Face 账号（部署用）

---

## 五、新手预期

做完这个单元你应该能：
1. 写一个带网页界面的 MCP Server
2. 理解同一个 Server 可以被不同语言的 Client 连接
3. 知道怎么把 MCP Server 部署到线上，而不是只在本地跑

这也是简历上"MCP 实战经验"的基础——你不只是学过概念，是真的做过完整的 Server + 部署 + 多客户端连接。
