# Agentic RAG 用例导论

**一句话总述：**本单元用 **Agentic RAG（智能体检索增强生成）**给 Alfred 打造一个"世纪舞会管家"工具——能回答关于舞会的一切问题（菜单、宾客、日程、天气），让 Alfred 全权管理整场晚会。这是可以复用到自己项目中的真实世界用例。

## 一、本单元要做什么

目标是：用 Agentic RAG 为 Alfred 创建一个**能回答舞会宾客问题的工具**。

- 这是 Agentic RAG 的**真实世界用例**，可以用于你自己的项目或工作中
- 建议：试试套用到你自己的业务场景，并在社区分享
- 可以使用课程中讨论的**任意框架**（smolagents / LlamaIndex / LangGraph），课程为每个框架提供代码示例

## 二、场景：一场难忘的舞会

**设定：**你决定举办本世纪最奢华气派的派对——丰盛宴席、迷人的舞者、知名 DJ、精美饮品、绚烂烟花……

Alfred 将**独自管理一切**。因此他需要：

1. **访问所有晚会信息：**菜单、宾客名单、日程、天气预报等
2. **晚会期间实时回答任何问题**，同时处理可能出现的突发状况

他不可能独自完成这一切——所以我们要确保 Alfred 拥有所需的**信息和工具**。

## 三、舞会硬性要求（Renaissance 三素养）

文艺复兴时代的"受过良好教育的人"需要三大特质，我们也要用知识打动宾客：

| 要求 | 说明 |
|-|-|
| **知识渊博** | 精通三大领域：**体育（sports）、文化（culture）、科学（science）** |
| **回避禁忌话题** | **政治（politics）和宗教（religion）**要在舞会上避开——避免因信仰和理念产生冲突 |
| **好主人的礼仪** | 了解宾客**背景**（兴趣和事业），还能在宾客之间分享故事 |
| **天气常识** | 掌握天气的**实时更新**，确定烟花燃放的最佳时机，让舞会华丽收尾 🎆 |

## 四、解决方案：RAG 训练

Alfred 需要海量信息来举办舞会。幸运的是，我们可以通过给他做 **RAG（检索增强生成）训练**来准备。

接下来的步骤：

1. **创建工具：**构建 Alfred 主持舞会所需的工具（检索、查询等）
2. **知识库：**把舞会信息（宾客、菜单、日程、天气）组织成可检索的知识源
3. **智能体化：**让 Alfred 能自主决定何时检索、检索什么、如何回答

## 五、为什么用 Agentic RAG？

| 传统 RAG | Agentic RAG |
|-|-|
| 固定流程：检索 → 拼接 → 生成 | 智能体自主规划：决定检索什么、何时检索、多轮检索 |
| 一次查询对应一次检索 | 可拆解复杂问题、多次检索、结合工具 |
| 难以应对突发情况 | 能动态决策，适合晚会这种动态场景 |

## 六、新手常见误区

- **误区1：以为 RAG 只是"检索+拼接"。**Agentic RAG 让智能体自主决定检索策略，更灵活。
- **误区2：知识库一次建好就完事。**晚会信息（天气等）会变化，需要实时更新渠道。
- **误区3：忽视禁忌话题约束。**给 Alfred 的指令里要明确"避开政治和宗教"。

## 七、本节小结

场景明确：Alfred 全权管理舞会，需要知识渊博（体育/文化/科学）、避开禁忌话题、了解宾客背景、掌握实时天气。接下来就是用 RAG + 工具把这些能力装进 Alfred。
