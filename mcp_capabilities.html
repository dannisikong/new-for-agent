MCP 四种能力：谁控制谁

🔧 Tools 工具

谁控制：模型

干什么：执行动作

有副作用：⚠️

要批准：是

📄 Resources 资源

谁控制：应用

干什么：读数据

有副作用：无

要批准：否

💬 Prompts 模板

谁控制：用户

干什么：选工作流

有副作用：无

要批准：否

🔄 Sampling 采样

谁控制：Server

干什么：反调 LLM

有副作用：间接

要批准：是

一次完整协作流程：
1. 用户选 Prompt → 2. Resources 取数据 → 3. 模型调 Tools 执行 → 4. Server 用 Sampling 补 LLM
💡 类比：Tools 是"动手做事"，Resources 是"翻资料"，Prompts 是"选剧本"，Sampling 是"Server 反向请 AI 帮忙"
